## What it does

`main.py` writes a single one-line joke about office life to
`entry.txt` in the output directory given by `MAKEFUN_OUTPUT_DIR`
(default `/output`). No network, no dependencies, no arguments —
just one line, under 200 characters.

## The joke

> The office birthday card has been circulating for signatures so long that the birthday person has had another birthday.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/grade-out-office python3 main.py
cat /tmp/grade-out-office/entry.txt
```
